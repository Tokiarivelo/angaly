# ANGALY AI Service

FastAPI microservice powering the deep-learning half of **Angaly Pattern
Studio**: inspiration-photo feature detection and measurement-based style
suggestions. Called over internal HTTP by the NestJS `ai-inference` /
`pattern-engine` modules — never by the frontend directly, and never produces
final pattern geometry itself (that's `@angaly/pattern-engine`'s job, the
deterministic "rules set" — see `docs/features/pattern-engine.md`).

## Why a separate service (and why Python)

Confirmed architecture decision (see `docs/phases/phase-0-foundation.md`):
model training/serving tooling (PyTorch, torchvision, scikit-learn) is
Python-native. Keeping it as its own service means the TypeScript apps never
need Python installed, and this service can be scaled/deployed independently.

## Structure

```
app/
  main.py         FastAPI app, routes — includes GET /v1/models (which backends are loaded)
  inference.py    Gemini (gemini-2.5-flash) calls — suggest_pattern_parameters always,
                  estimate_missing_measurements routes to local_model.py when
                  modelPreference == "LOCAL_STATISTICAL" and an artifact is loaded
  local_model.py  Self-hosted statistical model (trained sklearn IterativeImputer) —
                  see ml/scripts/train_measurement_model.py and docs/features/ai-model-settings.md
  size_charts.py  Standard size reference tables (mirrors packages/types/src/size-charts.ts)
  schemas.py      Pydantic request/response models — keep in sync with
                  PatternAiSuggestionRequest/Response, PatternMeasurementEstimation*
                  in packages/types/src/index.ts
tests/          pytest suite
ml/
  data/raw/     Downloaded ANSUR II CSVs (gitignored) — see train_measurement_model.py docstring
  models/       Trained .joblib artifacts (gitignored, generated by the training script)
  notebooks/    Training experiments (never imported by app/) — gitignored outputs
  scripts/
    train_measurement_model.py         Trains the local measurement-imputation model
    generate_standard_measurements.py  Generates size_charts.py's reference data
```

## Status (session 2026-09-15)

Two real model backends now exist for measurement estimation, selectable per-request
(`modelPreference`) and admin-controlled by default (`docs/features/ai-model-settings.md`):

- **`GEMINI`** (default) — `gemini-2.5-flash` via `google-genai` (requires
  `GEMINI_API_KEY`), grounded with the standard size chart. Also the only backend for
  `suggest-parameters` (cut/style suggestion) and `chat/assistant` — no local
  alternative exists there (see docs/features/ai-model-settings.md for why).
- **`LOCAL_STATISTICAL`** — a `sklearn.impute.IterativeImputer` trained on ANSUR II
  (real anthropometric survey data, ~6000 subjects), self-hosted, no network call.
  Artifacts are gitignored: run `python ml/scripts/train_measurement_model.py` (after
  downloading the ANSUR II CSVs — see the script's docstring for the source URLs) to
  produce them locally. `GET /v1/models` reports whether it's actually loaded.

Both paths degrade gracefully to a clearly-flagged fallback (`modelVersion: "fallback-*"`)
on any error — never a blocking exception.

## Local development

```bash
cd apps/ai-service
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Health check: `GET http://localhost:8000/health`. Interactive docs (dev only,
FastAPI's built-in Swagger UI): `http://localhost:8000/docs`.

To also enable `LOCAL_STATISTICAL` measurement estimation, download the ANSUR II CSVs
(URLs in `ml/scripts/train_measurement_model.py`'s docstring) into `ml/data/raw/`, then
run `python ml/scripts/train_measurement_model.py` — it prints held-out MAE per
measurement key and writes `ml/models/*.joblib`. Optional: the service works fine
without this step, it just reports `LOCAL_STATISTICAL` as unavailable.
