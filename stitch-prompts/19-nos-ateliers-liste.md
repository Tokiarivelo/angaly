# Page — Nos Ateliers (List + Map)

Purpose: overview of all Angaly workshop locations with an interactive map.

```text
Design the ANGALY "Nos Ateliers" page — the workshops/locations page for ANGALY, a high-end couture fashion house based in Madagascar.

BRAND CONTEXT & PALETTE (reuse exactly):
Primary Deep Navy #061938 (dominant), Primary Dark #041329, Navy Blue #0C2650, Royal Navy #18375D, Soft Navy #1E4574, Ivory background #F6F2E9, Warm Ivory #D8D3C8, Champagne #C5B190 (subtle accents), Antique Gold #936C3E (very sparing), Slate #5C697A, Warm Gray #8A877F, Border #D9D4CA, White #FFFFFF (limited). Headings: elegant serif (Cormorant Garamond or Playfair Display). UI/body: clean sans-serif (Inter or Manrope). Primary button navy/white. Secondary button outlined navy on ivory.

TOP NAVIGATION:
Standard ANGALY sticky nav bar with "Ateliers" active.

PAGE HEADER:
Ivory background, serif headline "Nos Ateliers", sans-serif subtext: "Venez découvrir notre savoir-faire dans l'un de nos ateliers."

LAYOUT — split screen:
LEFT (or top on mobile) — INTERACTIVE MAP:
A styled map panel with a custom muted, warm-toned map style (desaturated, navy/ivory tones rather than default bright map colors) showing pin markers for each atelier (navy pin with a small champagne dot) and any pickup points. Clicking a pin highlights the matching card in the list.

RIGHT (or below on mobile) — ATELIER LIST:
A vertical list of atelier cards, each with: a photo thumbnail, atelier name (serif), full address, opening hours (e.g. "Lun–Sam, 9h–18h"), a short services tag list (Essayages, Consultations, Retouches, Retrait de commandes), and a Secondary button "Voir l'itinéraire" plus a text link "Voir la fiche complète".

FEATURED ATELIER BANNER (optional, above the split layout):
A large photo banner of the flagship/main atelier with an overlay caption: "Notre atelier principal — Antananarivo" and a Primary button "Prendre rendez-vous ici".

FOOTER:
Standard ANGALY footer.

MOBILE BEHAVIOR:
Map on top (collapsible/expandable), atelier cards stacked below in a single column, each card's "Voir l'itinéraire" opens the native maps app.

AVOID:
default bright Google-Maps-blue styling clashing with the palette, cluttered pin icons, excessive gold, heavy shadows.

The page should feel like an invitation into a warm, welcoming, artisanal space.
```
